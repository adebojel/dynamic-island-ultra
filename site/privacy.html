Kebijakan Privasi

Kebijakan ini menjelaskan pemrosesan informasi oleh Dynamic Island Ultra. Aplikasi saat ini belum menyediakan akun atau server akun pengembang.

Informasi yang diproses

  • Notifikasi (opsional): jika Notification Access diaktifkan, judul dan teks dibaca untuk ditampilkan pada floating island. Preview diteruskan secara lokal melalui broadcast terbatas ke paket aplikasi. Izin dapat dicabut melalui Android.
  • Baterai: level dan status pengisian dibaca lokal.
  • Pengaturan dan catatan: preferensi, posisi island, status fitur, dan catatan disimpan di penyimpanan privat aplikasi.
  • Browser: situs dibuka lewat WebView dan dapat menerima IP, user-agent, cookie, serta data yang pengguna masukkan. WebView mendukung JavaScript dan DOM storage; situs dapat menyimpan cookie/data.
  • Pembaruan:** varian distribusi GitHub menghubungi GitHub untuk metadata rilis dan unduhan APK/checksum HTTPS sebelum membuka pemasang Android. Varian Google Play membuka Play Store untuk pembaruan dan tidak menggunakan izin pemasangan paket mandiri.
  • Iklan: Google Mobile Ads/UMP dapat memproses pengenal perangkat/iklan, IP, informasi perangkat, diagnostik, interaksi iklan, dan sinyal lain untuk pemuatan, pengukuran, keamanan, dan personalisasi jika diizinkan.
  • Premium: Google Play menangani transaksi/metode pembayaran. Aplikasi menerima data produk dan status pembelian/langganan; pengembang tidak menerima nomor kartu/kredensial.

Izin Android

Manifest bersama mencantumkan internet/jaringan, overlay, notifikasi, boot, dan foreground service. Izin REQUEST_INSTALL_PACKAGES hanya ada pada varian GitHub yang didistribusikan di luar Google Play untuk memasang pembaruan atas tindakan pengguna. Varian Google Play tidak mendeklarasikan izin tersebut dan menerima pembaruan dari Play Store. Overlay/Notification Access membutuhkan persetujuan khusus. Manifest saat ini tidak meminta lokasi, kontak, SMS, kamera, atau mikrofon.

Alat offline

Asisten lokal, kalkulator, diagnostik, catatan, dan preferensi diproses di perangkat. Asisten tidak menggunakan API AI cloud atau mengirim perintah ke server pengembang.

Pihak ketiga

Google (AdMob, UMP, Play), GitHub, dan situs web yang dibuka pengguna memproses data sesuai kebijakan masing-masing: Google Privacy, Google Ads data disclosures, GitHub Privacy.

Penyimpanan dan penghapusan

Preferensi dan catatan disimpan di perangkat. Pengguna dapat menghapusnya melalui pengaturan Android atau menghapus aplikasi. Pengembang tidak mengoperasikan server akun untuk menyimpan catatan atau preview notifikasi.

Consent, anak-anak, dan perubahan

Jika UMP mewajibkan pilihan privasi, formulir relevan ditampilkan sebelum permintaan iklan dan pintasan pilihan privasi tersedia. Aplikasi adalah utilitas umum, bukan layanan khusus anak. Kebijakan diperbarui bila SDK, izin, fitur, atau kewajiban hukum berubah.

Kontak

Ajukan pertanyaan melalui GitHub Issues. Jangan kirim password, OTP, keystore, atau private key.
