Kebijakan Privasi

Kebijakan ini menjelaskan pemrosesan informasi oleh Dynamic Island Ultra. Aplikasi saat ini belum menyediakan akun atau server akun pengembang.

Informasi yang diproses

  • Notifikasi (opsional): jika Notification Access diaktifkan, judul dan teks notifikasi dibaca secara lokal untuk proses preview; konten disembunyikan secara default, dapat dimatikan, dan dapat dibatasi dengan allowlist aplikasi. Notifikasi secret, ongoing, group-summary, serta notifikasi aplikasi sendiri disaring. Status panggilan generik mengikuti switch dan allowlist yang sama. Jika notifikasi pemutar menyediakan MediaSession, judul, artis, album, artwork, status putar/jeda, durasi, dan posisi dibaca lokal; kontrol pemutar hanya dijalankan setelah tindakan pengguna. Aplikasi tidak merekam atau mengunggah audio. Preview diteruskan melalui broadcast terbatas ke paket aplikasi dan tidak dikirim ke server pengembang. Izin dapat dicabut melalui Android.
  • Baterai: level dan status pengisian dibaca lokal.
  • Daftar aplikasi perangkat: aplikasi membaca nama, ikon, dan nama paket aplikasi yang memiliki aktivitas launcher agar pengguna dapat membukanya dari daftar aplikasi. Daftar ini diproses di perangkat dan tidak dikirim ke server pengembang atau layanan AI.
  • Pengaturan dan catatan: preferensi, posisi island, status fitur, dan catatan disimpan di penyimpanan privat aplikasi.
  • Browser: situs dibuka lewat WebView dan dapat menerima IP, user-agent, cookie, serta data yang pengguna masukkan. WebView mendukung JavaScript dan DOM storage; situs dapat menyimpan cookie/data.
  • Pembaruan: varian distribusi GitHub menghubungi GitHub untuk metadata rilis dan unduhan APK/checksum HTTPS sebelum membuka pemasang Android. Varian Google Play membuka Play Store untuk pembaruan dan tidak menggunakan izin pemasangan paket mandiri.
  • Iklan: Google Mobile Ads/UMP dapat memproses pengenal perangkat/iklan, IP, informasi perangkat, diagnostik, interaksi iklan, dan sinyal lain untuk pemuatan, pengukuran, keamanan, dan personalisasi jika diizinkan.
  • Premium: Google Play menangani transaksi/metode pembayaran. Aplikasi menerima data produk dan status pembelian/langganan; pengembang tidak menerima nomor kartu/kredensial.

Izin Android

Manifest bersama mencantumkan internet/jaringan, overlay, notifikasi, boot, dan foreground service. Izin REQUEST_INSTALL_PACKAGES hanya ada pada varian GitHub yang didistribusikan di luar Google Play untuk memasang pembaruan atas tindakan pengguna. Varian Google Play tidak mendeklarasikan izin tersebut dan menerima pembaruan dari Play Store. Overlay/Notification Access membutuhkan persetujuan khusus. Manifest saat ini tidak meminta lokasi, kontak, SMS, atau kamera. Izin RECORD_AUDIO dideklarasikan sebagai fitur perangkat opsional dan baru diminta setelah pengguna menekan kontrol input suara; pengenalan hanya memakai layanan on-device jika tersedia di Android/perangkat.

Alat offline

Asisten lokal, kalkulator, diagnostik, catatan, dan preferensi diproses di perangkat. Asisten tidak menggunakan API AI cloud atau mengirim perintah ke server pengembang.

Pihak ketiga

Google (AdMob, UMP, Play), GitHub, dan situs web yang dibuka pengguna memproses data sesuai kebijakan masing-masing: Google Privacy, Google Ads data disclosures, GitHub Privacy.

Penyimpanan dan penghapusan

Preferensi dan catatan disimpan di perangkat. Pengguna dapat menghapusnya melalui pengaturan Android atau menghapus aplikasi. Pengembang tidak mengoperasikan server akun untuk menyimpan catatan atau preview notifikasi.

Consent, anak-anak, dan perubahan

Jika UMP mewajibkan pilihan privasi, formulir relevan ditampilkan sebelum permintaan iklan dan pintasan pilihan privasi tersedia. Aplikasi adalah utilitas umum, bukan layanan khusus anak. Kebijakan diperbarui bila SDK, izin, fitur, atau kewajiban hukum berubah.

Kontak

Ajukan pertanyaan melalui GitHub Issues. Jangan kirim password, OTP, keystore, atau private key.

Voice input, sensors and file previews

Microphone access is requested only after the user activates voice input. The app uses an on-device speech recognizer only where Android reports one available; it does not silently switch to a cloud recognizer. Availability depends on Android version and installed language models.

Sensor readings are used while Sensor Kit is open and listeners stop when the screen is paused. Images and PDFs are selected through Android's document picker and previewed locally. QR/barcode scanning delegates to Google Play services Code Scanner; the app does not request camera permission for that feature.

Wicara AI offline

Model Wicara GGUF disertakan di dalam paket aplikasi dan berjalan secara lokal pada perangkat ARM64. Saat pertama diaktifkan, aplikasi menyalin model ke penyimpanan privat dan memverifikasi ukuran, header GGUF, serta SHA-256. Prompt percakapan Wicara diproses di perangkat; modul ini tidak mengirim prompt ke server AI, tidak memakai API key, dan tidak memiliki fallback AI cloud. Kalkulator, kontrol Android, serta diagnostik tetap diproses oleh kode lokal deterministik. Model sangat kecil dan dapat memberikan jawaban keliru.

Wicara dimuat hanya saat pengguna mengaktifkannya dan dilepas ketika layar asisten ditinggalkan. Pengguna dapat menghapus data aplikasi untuk menghapus salinan privat model.
